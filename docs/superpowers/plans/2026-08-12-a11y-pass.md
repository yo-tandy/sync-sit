**Goal:** Close issue #130's three gaps: sub-44px header hit targets, missing `prefers-reduced-motion` handling, and failing-contrast gray metadata text. (The issue's fourth item — tint contrast — is resolved by #134's computed brand ramp; note it, no work here.)

## Task 1: hit targets ≥44px in headers (both apps + shared TopNav)

Audit every icon-only/logo interactive element in: `packages/shared-ui/src/components/TopNav.tsx`, study `AppBar.tsx`/`FamilyAppBar.tsx`, sit `AppBar.tsx` (and any other header-owned icon buttons found by `grep -rn "h-8 w-8\|h-6 w-6" …` inside interactive elements). Fix by PADDING THE HIT AREA, never enlarging the glyph: e.g. wrap in `class="flex h-11 w-11 items-center justify-center -m-1.5"` (negative margin preserves the visual layout while the touch target grows to 44px) — adapt per site so headers don't visibly change height. Tests: extend the existing app-bar/TopNav component tests asserting the interactive element carries the ≥44px sizing classes (pin `h-11 w-11` or `min-h-11 min-w-11` on each fixed control).

## Task 2: prefers-reduced-motion

`packages/shared-ui/src/theme/base.css`: add the standard clause —
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
Both apps import base.css, so one clause covers everything (spinners become static — acceptable; they're `role`-less decoration next to text). Drift-guard: extend the existing theme test file (brandTokens-style, in study-web's shared-ui test dir) with one test asserting base.css contains the media query.

## Task 3: gray-400 text audit

~121 `text-gray-400` occurrences. `#9CA3AF` on white is 2.54:1 — fails AA for TEXT. Classify each:
- **Meaningful text** (metadata, timestamps, secondary copy a user must read) → `text-gray-500` (4.6:1).
- **Decorative/redundant** (icons WITH adjacent text labels, chevrons, dividers, placeholder-style hints duplicated elsewhere) → may stay gray-400; justify per file in the report.
- Placeholders (`placeholder:text-gray-400`) → stay (convention; content is a hint, and inputs also have labels).
Script the classification pass file-by-file (read context, don't blind-replace). Tests asserting gray-400 classes (if any) update with their sites.

Report includes: per-file gray-400 dispositions (changed vs justified), the list of fixed hit targets with before/after sizes, and a line for the issue that tint contrast is #134's.
